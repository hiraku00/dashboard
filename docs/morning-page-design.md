# モーニングページ（/morning-page）

Obsidian の「朝の書き物」（モーニングページ。2023年6月から毎日）を、日報とは別に、1ページ1行で D1 に持ち、画面で読む。

## なぜ日報の振り返りタブとは別か

日報の6節目「予定と振り返り」（[画面設計 §4.7](daily-report-view-design.md#47-振り返りタブ第5版)）は、**日報（画面ログ）のある日にだけ**付く。日報の最古は 2025-12-23 で、それ以前のモーニングページ（約885ページ）には付ける先が無い。そこで、日報と独立した入れ物を作る。日報のある日の予定と実績は、今までどおり日報の「振り返り」タブで読み、この画面からそこへ案内する。

## データ

`morning_pages`（1ページ1行。`migrations/0024_morning_pages.sql`、schema version 23）。**本文は置かない。**

| 列 | 内容 |
| --- | --- |
| `page_date` | 主キー。ページの日付 |
| `started_at` / `ended_at` / `minutes` | ヘッダーの表「時間」から。4時間を超える所要時間は書き間違いとして `NULL` |
| `place` | ヘッダーの表「場所」 |
| `outfit_top` / `outfit_middle` / `outfit_bottom` | ヘッダーの表「服装」（`上:シャツ(Uniqlo U)<br>中:Tシャツ(WhitesVille)<br>下:デニム(白)`）の上・中・下を、書いたままの値で（各100字まで）。括弧の中はブランドのことも色のこともあるので分けない。書かなかった段・服装の欄の無いページは空文字（`migrations/0025_morning_page_outfit.sql`、schema version 24） |
| `chars` | 本文の文字数（空白とURLだけの行を除く）。ヘッダーの「文字数」は3割のページにしか無いので、本文から数える |
| `yesterday` / `plan` / `notes` | そのページに書かれた「昨日のこと」「今日の予定」「気になったこと」（JSON の文字列配列、各400字・16件まで） |
| `extracted` | 上の3つを Claude で取り出したか。日報のある期間（2025-12-23 以降）は `0`（ヘッダーだけ） |
| `content_hash` | 同じ内容の再送を `skipped` にするための、内容のハッシュ |

## 取り込み

auto-daily-report の `morning_pages.py` が `POST /api/morning-pages`（service token のみ。1リクエスト50件まで）へ送る。`app/lib/morning-page-input.ts` が1件ずつ検証し（不正な件はその件の `error`）、`app/lib/morning-page-store.ts` が既存のハッシュと比べて、変わった・新しいページだけを1回の `DB.batch` で書く。何度送り直してもよい。

## 画面

`?tab=trend|month|notes&month=YYYY-MM&year=YYYY&q=`。D1 は1回の `batch` で読む（月ごとの集計と場所・開く月の行・その前日〜月末の日報の6節目・気がかりの年の分・検索）。前の作りのタブ名（`overview`・`days`）で来たら「月」で開く。

- **推移**（全期間）: 年で絞れる（全期間・各年）。書いた日（N/日数）・平均の所要時間・平均の文字数、月ごとの「書いた日数」の棒（場所の分類で積み上げ）、月ごとの平均の所要時間か文字数の棒（切り替え）。棒を押すとその月の「月」タブへ
- **月**: 年を選び、その年の12か月から選ぶ（データのある月だけ押せる）。前後の月へも動ける。月の数字、日ごとの所要時間の棒（色は場所の分類）、押した日の中身（昨日のこと・今日の予定・気がかり。初めは月の最後の日）、場所の内訳（分類ごとに、書いたままの名前と日数も添える）
- 押した日の中身には、服装（書いた段だけ）も出す
- **気がかり**: 年ごとの一覧（年はリンクで読み直し、月はその場で絞る）。検索語があれば、全期間の昨日のこと・予定・気がかり（日報の6節目の気がかりも）から検索

### 日報画面の服装

服装はその日の朝に書くので、日報 D の日次表示のヒーローに、ページ D の服装を1行で出す（`app/lib/queries/daily-report.ts` が日次のときだけ `morning_pages` の1行を読む）。6節目の振り返り（D+1 の朝のページ）とは向きが逆。服装を書いていない日は出さない。

同じ内容かの判定（`content_hash`）には、服装を書いたページでだけ服装を含める。服装の列を足す前に送ったページを、送り直しで全部 `updated` にしないため。

### 日報のある期間の中身

2025-12-23 以降のページは取り出しをしていない（ヘッダーだけ）ので、日報の6節目「予定と振り返り」（`daily_reports.reflection`）から補う（`app/lib/morning-page-model.ts`）。6節目は「日報 D の朝の予定」と「D+1 の朝の振り返り・気になること」から書かれるので、

- 日報 D の「予定と実績」の予定（予定外を除く）→ ページ D の「今日の予定」
- 日報 D の「PCの外の活動」→ ページ D+1 の「昨日のこと」
- 日報 D の `[気がかり]` → ページ D+1 の「気がかり」（`[持ち越し]` は出さない）

気がかりタブと検索は、6節目の「### 気になったこと・持ち越し」から後だけを読む（`substr(reflection, instr(...))`）。

### 場所の分類

場所は手書きで揺れる（「7F-中庭」「7F 中庭」「中庭」、「Focus 2」「Focus2」など）ので、`app/lib/morning-page-places.ts` の規則で意味ごとにまとめる: 自宅・共用スペース（住まいの建物の co-working・中庭・Focus・R棟・Sky など。「自宅(co-working)」もここ）・実家（「自宅（槻木）」もここ）・知人・親戚の家・宿泊先・カフェ・店・移動中・その他。新しい書き方の場所は「その他」に落ちるので、増えたら規則に足す。

## 限界

- 「昨日のこと」は、そのページに書かれた分だけ。前日の出来事を書かない日（2023年に多い）は空になる
- 予定の達成（済・未）は出さない。日報のある期間は、日報の振り返りタブで読む
- 日報のある期間でも、日報の無い日（PCの記録が無い日）のページは、ヘッダーだけのまま
- 取り出しは Claude が書くので、人名・店名・時刻に誤りがありうる
