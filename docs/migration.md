# データ移行

## 共通手順

1. 移行元の原本をローカルのGit管理外へバックアップする。
2. 本番D1/R2の現在件数とバックアップを確認する。
3. 移行スクリプトをdry-run相当の読み取りで実行し、対象件数を確認する。
4. 本番へ投入する。
5. 件数、重複、文字化け、日付、リンク、R2オブジェクトを検証する。
6. 画面/APIで表示を確認する。

## Watch List

`scripts/import-watch-list.mjs` で既存MarkdownをD1へ取り込みます。source/external IDと正規化URLによる重複判定を確認し、再実行で重複項目を作らないことを検証します。

## TextTube

`scripts/import-text-tube.mjs` でメタデータをD1、本文をR2へ移行します。本文ファイルとrevisionの対応、GFM表・Mermaidコードの保持、目次対象の見出しを確認します。

## Manage Asset

`scripts/import-manage-asset-history.mjs` は既存履歴をD1へ移行します。stETH、Lido報酬、保管場所、通貨、USD/JPY、日付の境界を重点的に確認します。

日次スナップショットは日付とsourceをキーに冪等に投入します。過去データを欠損日としてゼロ補間したり、当日初回データを前日差として誤計上したりしないことが重要です。

## 移行後チェック

- 最新日付が想定どおりか
- 総資産と通貨別合計が一致するか
- stETHが配分、保有資産、通貨推移のすべてに含まれるか
- 保管場所別合計が通貨別合計と整合するか
- TextTube本文の表・Mermaid・目次が表示されるか
- 再実行で行数が増えないか
