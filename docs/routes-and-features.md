# 画面・機能一覧

## ポータル

| パス | 内容 |
| --- | --- |
| `/` | 各機能へのカード、認証済み基盤の状態、主要データへの導線 |
| 共通ヘッダー | ホーム、Watch List、TextTube、Manage Asset、To Do、使用量へのナビゲーション |

## Watch List

`/watch-list` では、D1に保存された項目をページングして表示します。検索語（タイトル、内容、人物、番組名、リンクのURLと表示名に部分一致）、コンテンツ種別、ステータス、優先度、クリエイターなどで絞り込み、項目の追加・編集・削除、リンク管理を行います。追加フォームでは、公開YouTube動画のURLからチャンネル名（番組・連載名）、タイトル、リンクを入力でき、取得後も保存前に各項目を編集できます。取得で更新するのはこの3項目だけで、人物・媒体、種別、内容などの入力済みの項目と、既存のリンクは上書きせず残します（リンクは追加）。一覧の各行のタイトルの右隣（スマホ幅ではタイトルの下）に、リンク先のサムネイルを表示します。YouTubeのリンクは動画IDから画像URLを導き（保存しない）、それ以外は保存時にリンク先ページのog:image（なければtwitter:image）を取得して`items.thumbnail_url`に保存します。`<meta http-equiv="refresh">`だけを返すページ（t.coなど）は転送先まで辿ります。取得に失敗しても保存は失敗せず、画像なしの行になります。リンクを変えなければ編集のたびに取り直さず、画像が取れなかった項目はリンクを変えると再度取得します。インポート（`POST /api/imports`）も保存時に同じ取得を行い、1回のリクエストで取得するのは先頭16件までです（超えた分は画像なしで保存し、レスポンスの`thumbnails`に件数を返します）。サムネイルはリンクから導く付加情報のため、インポートのペイロードでは受け取りません（JSONエクスポートには`thumbnail_url`が含まれ、CSVには含まれません）。インポート履歴とJSON/Markdownのバックアップ導線も提供します。

## To Do

`/todo` は、受信箱・今日・進行中・完了の列を持つ日別看板です。単発タスクは実施日と時刻を指定して追加でき、繰り返しタスクは毎日または指定曜日・時刻のテンプレートとして保存します。対象日のボードを開くとテンプレートから実行カードを冪等に生成します（テンプレート作成日より前の日付には生成されません）。各列のカードは時刻昇順（未設定は末尾）、同時刻はタイトル順に並びます。繰り返しタスクは一覧から編集・停止／再開・削除ができます。カードは詳細シートで編集し、列間の移動、完了、削除ができます。

## TextTube

- `/text-tube`: ライブラリ一覧、検索、並び順、ステータス、コンテンツ種別の切り替え
- `/text-tube/studio`: タイトル、チャンネル、説明、リンク、詳細Markdownの作成・編集
- `/text-tube/watch/:id`: 本文閲覧。見出しからの目次、GFMテーブル、コード、Mermaid図を表示

詳細本文はR2に保存し、D1には検索・一覧表示に必要なメタデータとR2オブジェクトキーを保存します。

## Manage Asset

- `/manage-asset`: 総資産、前日差、資産推移、資産配分、保有資産
- `/manage-asset/locations`: 保管場所ごとの内訳
- `/manage-asset/currencies`: 通貨ごとの推移、期間、履歴
- `/manage-asset/sync`: 各ソースの最終取得日、同期状況、古いデータの警告
- `/manage-asset/settings`: 表示・同期関連の設定

全画面がServer Componentで実装されたネイティブなReact実装で、他画面と同じくRSC＋クライアント島の構成です（旧来のiframe埋め込みは撤去済み）。表記・桁数・計算ロジックは既存Manage Assetの仕様を踏襲し、`/manage-asset`・`/currencies`・`/locations`は起動時に読み込んだ`state`/`history`をタブ切り替えで共有します。stETHを含むすべての資産・保管場所・通貨のデータは同じスナップショット系列から表示します。設定・データ更新は読み取り専用（取引所・ウォレットの追加/編集はMac側collectorの役割）。

## ストレージ

`/settings/storage` では、D1/R2の使用量をカテゴリ別に表示します。R2の実使用量とアプリケーションが管理するオブジェクト台帳を照合し、日次の集計と上限に近づいた場合の警告を確認します。
